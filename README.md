# welcome to the Animal Portfolio Centre!
## TITLE: ANIMAL PORTFOLIO CENTRE
This is a educational website to explore some of the weirdest and coolest animals on the earth and have the opportunity to learn about them.

The purpose of this project is to teach people about some of nature's most overlooked beings, and educate them on their abilities.

## features
- pics about cool animals
- information about the animals
- quiz questions to reinforce knowledge of people who just learned about the animals.
- a restart button to retake the quiz if you dont do too well
- a score tracker

### languages used
- html (to add text, and photos)
- css (for styling the website)
- javascript (to make buttons work)

## what i learned
- I learned how to keep websites organized.
- how to style websites
- how buttons work
